# 🌍 Wanderlust

Wanderlust is a full-stack web application for discovering and sharing travel listings.

## 🚀 Features

- User signup and login
- User authentication
- Create new travel listings
- View listing details
- Edit and delete your listings
- Add reviews and ratings
- Flash messages
- Form validation
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Passport.js
